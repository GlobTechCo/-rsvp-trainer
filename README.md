# RSVP Trainer

Повноцінний браузерний тренажер швидкого читання методом Rapid Serial Visual Presentation.

## Можливості
- показ слів по одному в центрі екрана;
- швидкість 60–1200 слів/хв;
- паузи на розділових знаках;
- додатковий час для довгих слів;
- розмір слова;
- старт / пауза / скидання;
- власний текст і демо-текст;
- таймер, лічильники та кількість сесій;
- світла й темна тема;
- клавіатурні скорочення Space та R;
- робота без сервера, прямо у браузері.

## Запуск
Відкрийте `index.html` у браузері або опублікуйте репозиторій через GitHub Pages.
